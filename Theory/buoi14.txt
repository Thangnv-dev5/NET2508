cách tạo DB: chuột phải vào mục database-->New Database--> đặt tên databasse--> Create
Cách tạo table: Chọn vào db muốn tạo table--> trỏ vào mục table--> chuột phải--> new--> table
Cách thêm trường cho bảng:
	Ví dụ: 
		column Name : Id
		Data Type: int
		Allow Nulls: tích chọn
Cách setting khóa chính: chọn trường muốn setting: chuột phải--> primary key
cách để khóa chính tự auto tăng khi thêm data: chọn vào khóa chính--> nhìn xuống mục column properties--> Identity Specification --> nhìn xuống dòng (Is Identity) chuyển chế độ sang Yes
+ tên các trường phải in hoa chữ cái đầu tiên 
+ nchar: ký tự
+ nvarchar: dạng chuỗi
